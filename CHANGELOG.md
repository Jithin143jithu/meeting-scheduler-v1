# Changelog

All notable changes to Meeting Scheduler will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-12

### Added
- Initial production release
- User authentication (registration, login, forgot password)
- Email verification system
- User dashboard with meeting management
- Availability management (weekly schedule, exceptions)
- Meeting type creation and management
- Public booking page with calendar picker
- Smart booking engine with slot locking
- Double-booking prevention
- Timezone support and conversion
- Email notifications for bookings
- Customizable email templates
- Google Calendar integration
- Calendar event sync
- Admin dashboard
- User management panel
- System settings
- Activity logging
- Rate limiting
- API endpoints with Sanctum authentication
- Bootstrap 5 responsive design
- Complete database schema
- Unit and feature tests
- Comprehensive documentation

### Security
- CSRF protection
- XSS protection
- SQL injection prevention
- Password hashing
- Rate limiting
- Email verification
- Activity logging
